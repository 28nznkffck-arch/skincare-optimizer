# 成分の表記・解説の管理

更新日：2026-11-23 ／ v0.9.22

## 表示と元データ

`catalog/`・`catalog-men/` の主要成分名はメーカー表示の記録として残す。商品・価格・使用量・肌悩み点のCSVは今回変更していない。

`dist/ingredient-options.js` の `canonicalIngredient()` を、各版の選択肢、商品カード、保存済み成分指定の移行、成分指定の照合に使う。全角英数・括弧・スラッシュはNFKCで統一し、確認した同義語だけを対応表でまとめる。カタカナの長音を一律にハイフンへ変換したり、植物名の似たエキスを機械的に同一化したりしない。

選択肢は各版の掲載中商品の主要成分から作る。男女版を合わせて共通化することも、解説の掲載数で制限することもしない。表記統一で重複が減ることはあるが、別の成分を削除するものではない。CSVの主要成分は全成分表示ではないため、未登録の配合成分まで検索できるとは限らない。

## まとめない成分と照合の変更

同じ解説カードに並べることと、同じ成分として照合することを分ける。

- レチノールと酢酸レチノール、アスコルビン酸と各誘導体、トコフェロールと酢酸トコフェロールは別。
- ヒアルロン酸Naとアセチル化体・加水分解体・架橋体・カチオン化体は別。
- セラミドNP・NG・AP・番号付き原料と花王SLEは一律にまとめない。
- グリセリンと濃グリセリン、ソルビトールとソルビット液、水溶性コラーゲンの(F)・液など、原料規格・状態を含む登録名は、今回の対応表にないものを勝手に削らない。L体の指定も一律には削除しない。
- 植物エキスの抽出部位・番号・油溶性などは残す。カモミラETと一般のカミツレエキスは別。
- ライスパワーNo.11・11+・6・7-Aはそれぞれ別。薬用での用途も区別する。

以前の成分指定は部分文字列一致だったため、「レチノール」で「酢酸レチノール」、「グリセリン」で「ジグリセリン」などが該当する問題があった。v0.9.22からは正規化後の完全一致にする。優先の10点・必須判定・任意品目を候補に入れる判定はすべて同じ照合を使う。「アミノ酸」「ビタミンC誘導体」のような総称の登録名も、総称として登録されている商品との一致を表す。

肌悩み点・7/3/1倍の重複処理・手間点・成分種類数の加点・探索アルゴリズムは変更していない。成分指定があるときは、同義語の追加と誤った部分一致の修正により候補が変わる場合がある。成分種類数の採点は従来どおり元の主要成分文字列を用いる。

## 解説の編集・生成

- 編集元：`data/ingredient-guide.mjs`。役割・選ぶ目安・登録名・研究の対象と限界・一次資料を記録。
- 出力：`dist/ingredients.html`（JavaScriptなしでも読める本文）と `dist/ingredient-guide-index.js`（アプリのリンク用）。`npm run guide:build` で生成。
- `npm run guide:check` とテストで、男女両DBのすべての選択名から実在する解説IDへ到達できること、解説IDの重複がないこと、生成物の一致を確認。今後成分を追加したときも未掲載を検出する。
- 解説は48項目。関連成分をまとめて説明するため、成分の選択数とは異なる。従来の5つのアンカーは保持。
- 検索は別表記・全角半角・ひらがな／カタカナに対応し、役割でも絞り込める。検索で本文を隠していても、目次やハッシュ移動では絞り込みを解除する。

## 論文の扱い

確認日は編集元の `checkedOn`。各カードに原著のPubMedリンク・PMID、確認できたDOI、試験の種類・条件と限界を記録する。メーカーの用途・原料資料を臨床試験として表示しない。論文番号を確認できない研究紹介には番号を作らず、メーカーの公開資料へリンクする。

既存5項目の参考論文に、レチノール（PMID 17515510）、トラネキサム酸（27135282）、アスコルビン酸（12823436）、グリセリン／ワセリン配合クリーム（31532576）を追加。細胞・動物・ヒトでの試験、対照群の有無、使用部位・濃度・期間を区別する。内服・注射の研究を外用化粧品へ当てはめない。

価格・JAN・メーカー成分表示の照合ルールは従来の各カタログの記録を優先し、この解説に記載した原料情報から商品DBの値を作らない。
