# 成分の表記・解説の管理

更新日：2026-11-23 ／ v0.9.23

## 表示と元データ

`catalog/`・`catalog-men/` の主要成分名はメーカー表示の記録として残す。商品・価格・使用量・肌悩み点のCSVは今回変更していない。

商品カードは `keyIngredients` のメーカー記録をそのまま表示する。商品表示を、選択欄のまとまりや正規化名で書き換えない。

`dist/ingredient-options.js` では、同義語の確認用 `canonicalIngredient()` と、選択用の分類 `ingredientSelection()` を分ける。同義語の確認では全角英数・括弧・スラッシュをNFKCで統一し、根拠のある別名を対応表でまとめる。カタカナの長音は一律にハイフンへ変換しない。

選択肢は各版の掲載中商品の主要成分から、`ingredientSelection()` でまとまりを作って五十音順に表示する。女性174・男性89項目。男女版のDBを共通化したり、選択できる成分を解説の掲載数で制限したりしない。CSVの主要成分は全成分表示ではないため、未登録の配合成分まで検索できるとは限らない。

## 選択欄のまとまり

「この仲間のどれかを含む商品を使いたい」という指定にする。化学物質・原料規格・濃度・効果が同一という意味ではない。

| 選択名の例 | 含める種類・表示名の例 |
| --- | --- |
| ヒアルロン酸 | ヒアルロン酸、Na／ナトリウム塩、加水分解、アセチル化、架橋体、カチオン化体、ヒアルロン酸発酵液 |
| コラーゲン | 水溶性、加水分解、トリペプチドF、サクシニルアテロコラーゲンなど |
| セラミド | NP・NG・AP・番号付き原料、N-ステアロイルジヒドロスフィンゴシン、セラミド機能成分（疑似セラミド） |
| グリセリン | グリセリン・濃グリセリン。ジグリセリンなどは別項目 |
| ビタミンC | アスコルビン酸と、登録されたビタミンC誘導体 |
| ビタミンE | トコフェロールと酢酸トコフェロール |
| スクワラン | 植物性・シュガースクワランを含む |

このほか、ソルビトール、グリチルレチン酸ステアリル、アルギニン、セリン、ツボクサ、ハトムギ、カミツレ、ユーカリ、ショウガ、チャ葉、酵母の登録名を整理する。18組の完全な対応は `INGREDIENT_FAMILIES` が編集元。抽出部位などが異なる植物原料も、選びやすくする分類としてまとめる場合があり、同じ成分・同じ効能と断定しない。

必須・優先の10点加点・任意品目を候補に入れる判定は、すべて同じ選択名に分類されるかで照合する。過去に保存した「ヒアルロン酸Na」なども、読み込み時に「ヒアルロン酸」へ移行する。元の成分名を変換したり、部分文字列一致で関連のない成分を拾ったりしない。

## 分けて扱うもの

メーカー表示、化学的な同義語、使ってみたい成分の分類は別管理。ヒアルロン酸の種類やセラミドの種類は選択欄でまとめるが、原料名・性質の違いは解説とメーカー情報に残す。

レチノールと酢酸レチノール、グリセリンとジグリセリン、セリンとメチルセリン、保湿のアミノ酸とアミノ酸系洗浄成分、カモミラETとカミツレエキス、ユーカリエキスとユーカリ葉油は別の選択項目にする。ライスパワーNo.11・11+・6・7-Aも薬用での用途が異なるため別項目。

肌悩み点・7/3/1倍の重複処理・手間点・成分種類数の加点・探索アルゴリズムは変更していない。成分指定があるときは、その仲間のいずれかを含む商品が対象になるため、以前より候補が広がる場合がある。成分種類数の採点は従来どおり元の主要成分文字列を用いる。

## 解説の編集・生成

- 編集元：`data/ingredient-dictionary.mjs` は成分名ごとの主な用途・短い説明・種類の補足を管理。`data/ingredient-guide.mjs` は研究の対象・限界・一次資料の記録として利用する。
- 出力：`dist/ingredients.html`（JavaScriptなしでも読める本文）と `dist/ingredient-guide-index.js`（アプリのリンク用）。`npm run guide:build` で生成。
- `npm run guide:check` とテストで、男女両DBのすべての選択名から実在する解説IDへ到達できること、解説IDの重複がないこと、生成物の一致を確認。今後成分を追加したときも未掲載を検出する。
- 解説は213項目。肌悩み・役割別の大見出しを廃止し、成分名の読みの五十音順に並べる。目次は「あ行・か行…」。各見出しに「主な用途」と短い説明を載せ、種類・メーカー表示例と研究・出典は開いて読めるようにする。
- メーカー表示の例と、配合製品の公式URLも各項目に掲載。元の48項目のアンカーは互換用に残す。
- 検索は別表記・全角半角・ひらがな／カタカナに対応。役割別の選択欄は置かない。検索で本文を隠していても、目次やハッシュ移動では検索を解除する。

## 論文の扱い

確認日は編集元の `checkedOn`。各カードに原著のPubMedリンク・PMID、確認できたDOI、試験の種類・条件と限界を記録する。メーカーの用途・原料資料を臨床試験として表示しない。論文番号を確認できない研究紹介には番号を作らず、メーカーの公開資料へリンクする。

既存5項目の参考論文に、レチノール（PMID 17515510）、トラネキサム酸（27135282）、アスコルビン酸（12823436）、グリセリン／ワセリン配合クリーム（31532576）を追加。細胞・動物・ヒトでの試験、対照群の有無、使用部位・濃度・期間を区別する。内服・注射の研究を外用化粧品へ当てはめない。

価格・JAN・メーカー成分表示の照合ルールは従来の各カタログの記録を優先し、この解説に記載した原料情報から商品DBの値を作らない。
