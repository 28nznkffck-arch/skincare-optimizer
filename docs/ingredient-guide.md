# 成分の表記・解説の管理

更新日：2026-11-24 ／ v0.9.32

## 表示と元データ

`catalog/`・`catalog-men/` の「配合成分」には、全563品の全成分表示を省略せず表示順に保存する。選択肢や解説の有無は登録条件に使わない。原文・出典URL・出典種別・確認日もCSVと `ingredient-sources.json` に保持する。[全成分登録記録](ingredient-coverage-audit.md)を参照。価格・使用量・肌悩み点の元データは変更していない。

商品カードは `keyIngredients` のメーカー記録をそのまま表示する。商品表示を、選択欄のまとまりや正規化名で書き換えない。

`dist/ingredient-options.js` では、同義語の確認用 `canonicalIngredient()` と、選択用の分類 `ingredientSelection()` を分ける。同義語の確認では全角英数・括弧・スラッシュをNFKCで統一し、根拠のある別名を対応表でまとめる。カタカナの長音は一律にハイフンへ変換しない。

選択肢は各版の掲載中商品の配合成分から、`ingredientSelections()` で複合原料の構成も認識し、五十音順に表示する。女性1150・男性467項目。解説の掲載数で登録・選択を制限しない。成分索引1264項目のうち、従来の一次資料付き205項目は既存の根拠を保持し、新しい名前は配合表示の出典と「用途の確認中」を表示する。`npm run ingredients:check` は選択用の辞書を使わず原本記録の全項目・順序・原文・出典・確認日と照合する。新しいJANや公式URL変更時も原本を確認する。

## ビタミンA表示名と重複候補の追加整理（v0.9.32）

「使ってみたい成分」の「ビタミンA」を**「レチノール(ビタミンA)」**に改名。「ビタミンA」「レチノール」「酢酸レチノール」「パルミチン酸レチノール」「ビタミンA油」は同じ選択カテゴリを参照する。成分原文や成分別の効能を同一視せず、旧「ビタミンA」カテゴリのURLアンカーと保存値は引き継ぐ。

**グリチルリチン酸ジカリウム**は「2K」「二カリウム」の既存同義語に加え、メラノCC 1品の配合成分原文にある「グリチルリチリン酸ジカリウム」を1文字違いの表記として名寄せした。原文自体は修正しない。正式な原料名は[厚生労働省の医薬部外品添加物リスト](https://www.mhlw.go.jp/web/t_doc?dataId=00tc7231&dataType=1&pageNo=1)で確認。「グリチルリチン酸アンモニウム」「グリチルレチン酸ステアリル」は別成分として残す。

**その他の同義語・表記整理（21組）**：Naとナトリウム、PEG-60とPEG60、水添ヒマシ油、カルボキシメチルセルロースNa、ピロ亜硫酸Na、メタリン酸Na、ポリアクリル酸Na、ミリストイルメチルタウリンNa、セテアレス-25、パルミチン酸エチルヘキシル、オクチルドデカノール、ライスパワーNo.6の登録商標表記、サクランの®表記、HCl／HCIや枝／技などの誤記と思われる形もメーカー原文を残して名寄せした。

**選択用の同系統グループ（15組）**：オリーブ油、ローズマリー油、アスナロ・ツバキ由来エキス、加水分解コンキオリン、コレステロール、フィトステロール、ラウロイルアスパラギン酸Na、サクシノグリカン、メチルセリン、ソルビタン脂肪酸モノエステル3種、ポリグリセリン、PEG水添ヒマシ油。加えて「アロエエキス-2」を既存のアロエエキスへ統合。液状原料・植物部位・脂肪酸構造・PEG鎖長が異なる場合は選択上のみのグループで、化学的な同義語と混同しない。グリセリンとジグリセリン、ローズマリー油とローズマリーエキスは別の項目。

今回の対象は男女計563商品の元データを維持して**女性1150・男性467件、共通索引1264項目**。旧版の索引1309項目のリンクは全て新しいカードのアンカーとして維持した。薬用の有効成分・採点ルール・成分出典に変更はない。

## アーティチョーク・ビタミン類・複合原料（v0.9.31）

**アーティチョーク**：「アーティチョークエキス」と「アーチチョーク葉エキス」を同じ選択名にする。原料メーカー[一丸ファルコス](https://www.ichimaru.co.jp/dev/cosmetics/261)の化粧品表示／医薬部外品表示名の対応を参照。メーカーの表示名と配合成分の原文は書き換えない。

**ビタミン類**：「ビタミンA」へレチノール・酢酸レチノール・パルミチン酸レチノール・ビタミンA油、「ビタミンB6」へピリドキシンHCl・塩酸ピリドキシン等、「ビタミンC」へアスコルビン酸硫酸2Naやリン酸L-アスコルビルマグネシウム、括弧の説明が付いたアスコルビン酸類、「ビタミンE」へ天然ビタミンE・トコフェリルグルコシドも含める。これは**使ってみたい成分の分類**であり、同一の化合物・有効成分・配合率・効果を示さない。レチノールのシワ改善の根拠はビタミンA油やレチノールエステルへ外挿しない。塩酸ピリドキシンとビタミンB6の対応は[厚生労働省の医薬部外品原料規格](https://www.mhlw.go.jp/content/000839905.pdf)を参照。

**3成分の複合原料**：「アクリル酸ナトリウム・アクリロイルジメチルタウリン酸ナトリウム共重合体／イソヘキサデカン／ポリソルベート80」は、[SEPPICのSIMULGEL EG](https://www.seppic.com/en-IN/product/simulgel-eg)と一致する複合原料の表示。12商品でメーカーの原文を確認済み。元の全成分表示は分割せず、**選択・検索・解説上のみ**明示された3成分をそれぞれ認識する。原文にスラッシュが含まれていても一律に分割しない（高分子や脂肪酸の原料名にもスラッシュがあるため）。既存の成分名リンク1,324件分のアンカーも引き継ぐ。

女性版1187・男性版485の選択肢、共通の成分解説1309項目。商品のJAN、価格、原料の原文、使用量、肌悩み点は変更しない。指定成分に対する検索対象は新しくまとめた成分群・複合原料の構成成分へ広がる。

## グリセリン・グリセリル等の表記整理（v0.9.30）

「グリセリル」はグリセリン由来の化学構造を表す場合があり、無条件でグリセリンと同一化しない。グリセリン・濃グリセリンは同じ選択名、エチルヘキシルグリセリンはそのエーテルとして別項目、グリセレス-26は酸化エチレン付加物として別項目。ステアリン酸グリセリルの通常型と自己乳化型(SE)も区別する。

エチルヘキシルグリセリンとグリセリンモノ2-エチルヘキシルエーテル等の名称対応は[原料商社](https://fuji-kasei-database.com/materials/1159/)、ベタインとトリメチルグリシンは[旭化成ファインケム](https://www.asahikasei-fc.jp/product/amino/aminocoat/)、エデト酸二ナトリウムとEDTA-2Naは[マツモト交商](https://matsumoto-trd.com/material/materialdetail.php?materialid=12)に照合。原料規格・分子量・抽出法で異なるものは選択用の系列とし、完全な同義語には含めない。ビタミンC/E・ヒアルロン酸・セラミドの全成分に見つかった既存未統合表記も補完。

男性版における販売名の付着と長い成分の結合を6品で修正。選択肢と成分索引の再生成により、女性1200・男性491項目、共通索引1324項目となった。旧リンクは不正な成分名7項目を除いて引き継いだ。原文を修正するのではなく、商品マスターの個々の成分としての区切りだけ再照合し原本記録と一致させる。[訂正記録](../catalog-men/ingredient-parsing-audit-2026-11-23.md)。

「使ってみたい成分」の表示グループを62組増やし、既存5組も補完。女性1245件、男性505件、成分索引1380項目。メーカー表示の全成分と原文は保持。

### 原料規格の番号と注釈（v0.9.26）

「アロエエキス(2)」は[厚生労働省の原料名リスト](https://www.mhlw.go.jp/web/t_doc?dataId=00tc5776&dataType=1&pageNo=1)に成分コード520095として掲載され、[メーカーの成分表示](https://onlineshop.finetoday.com/products/uno-54)にも使われる名称。(2)は脚注・配合濃度ではなく、原料規格の区分。[PMDA掲載の規格](https://www.pmda.go.jp/files/000240227.pdf)では、アロエの葉の液汁からアロインを除去して得た粉末を、水・エタノール・PG・BGなどで抽出または溶解した原料と定義されている。「油溶性甘草エキス(2)」も[原料供給元の医薬部外品名称](https://www.cosfa.co.jp/business/cosmetics/products/amakusa/)で確認した。

これら2項目は選択欄と解説見出しだけを簡略化し、メーカー表示・旧設定・旧解説URLは保持する。括弧を一括削除する処理は使わない。POE(26)グリセリンの数字や、トリ（カプリル酸／カプリン酸）グリセリルの括弧も保持する。

男女の主要成分・有効成分欄を点検し、雪肌精 ホワイト クリーム ウォッシュ（JAN 4971710262131）で説明文の混入1件を訂正した。[公式ページ](https://sekkisei.jp/site/blue/g/gMTNC/)の全成分は「酸化チタン」で終わり、その後のハトムギ発酵エキスに関する別行の説明が同じ成分としてつながっていた。価格・使用量・採点は据え置き。`catalog-csv.js` は注釈記号や説明文を含む成分欄を読み込み時に拒否し、正式な番号・構造名の括弧を受理する。

## 分けて扱うもの

メーカー表示、化学的な同義語、使ってみたい成分の分類は別管理。ヒアルロン酸の種類やセラミドの種類は選択欄でまとめるが、原料名・性質の違いは解説とメーカー情報に残す。

グリセリンとジグリセリン、セリンとメチルセリン、保湿のアミノ酸とアミノ酸系洗浄成分、カモミラETとカミツレエキス、ユーカリエキスとユーカリ葉油は別の選択項目にする。ライスパワーNo.11・11+・6・7-Aも薬用での用途が異なるため別項目。レチノールと酢酸レチノールは同じ「ビタミンA」を選択して探せるが、効果の評価では別の化合物として扱う。

肌悩み点・7/3/1倍の重複処理・手間点・成分種類数の加点・探索アルゴリズムは変更していない。成分指定があるときは、その仲間のいずれかを含む商品が対象になるため、以前より候補が広がる場合がある。成分種類数の採点は登録された配合成分の文字列を用いる。v0.9.28から全成分を入力するため、成分指定の候補や種類数による加点が変わる場合がある。

## 解説の編集・生成

- 編集元：`data/ingredient-dictionary.mjs` は成分名ごとの主な用途・短い説明・種類の補足を管理。`data/ingredient-guide.mjs` は研究の対象・限界・一次資料の記録として利用する。
- 出力：`dist/ingredients.html`（JavaScriptなしでも読める本文）と `dist/ingredient-guide-index.js`（アプリのリンク用）。`npm run guide:build` で生成。
- `npm run guide:check` とテストで、男女両DBのすべての選択名から実在する解説IDへ到達できること、解説IDの重複がないこと、生成物の一致を確認。今後成分を追加したときも未掲載を検出する。
- 解説の既存205項目を含めて現在1264項目。肌悩み・役割別の大見出しを廃止し、成分名の読みの五十音順に並べる。目次は「あ行・か行…」。各見出しに「主な用途」と短い説明を載せ、種類・メーカー表示例と研究・出典は開いて読めるようにする。
- メーカー表示の例と、配合製品の公式URLも各項目に掲載。元の48項目のアンカーと、統合前の成分名から作られた見出しIDを互換用に残す。
- 検索は別表記・全角半角・ひらがな／カタカナに対応。役割別の選択欄は置かない。検索で本文を隠していても、目次やハッシュ移動では検索を解除する。

## 論文の扱い

確認日は編集元の `checkedOn`。各カードに原著のPubMedリンク・PMID、確認できたDOI、試験の種類・条件と限界を記録する。メーカーの用途・原料資料を臨床試験として表示しない。論文番号を確認できない研究紹介には番号を作らず、メーカーの公開資料へリンクする。

既存5項目の参考論文に、レチノール（PMID 17515510）、トラネキサム酸（27135282）、アスコルビン酸（12823436）、グリセリン／ワセリン配合クリーム（31532576）を追加。細胞・動物・ヒトでの試験、対照群の有無、使用部位・濃度・期間を区別する。内服・注射の研究を外用化粧品へ当てはめない。

価格・JAN・メーカー成分表示の照合ルールは従来の各カタログの記録を優先し、この解説に記載した原料情報から商品DBの値を作らない。
