# 成分の表記・解説の管理

更新日：2026-11-23 ／ v0.9.27

## 表示と元データ

`catalog/`・`catalog-men/` の主要成分名はメーカー表示の記録として残す。v0.9.26では雪肌精の洗顔料1品で、成分末尾につながった説明文を公式表示と照合して訂正した。価格・使用量・肌悩み点のCSVは変更していない。

商品カードは `keyIngredients` のメーカー記録をそのまま表示する。商品表示を、選択欄のまとまりや正規化名で書き換えない。

`dist/ingredient-options.js` では、同義語の確認用 `canonicalIngredient()` と、選択用の分類 `ingredientSelection()` を分ける。同義語の確認では全角英数・括弧・スラッシュをNFKCで統一し、根拠のある別名を対応表でまとめる。カタカナの長音は一律にハイフンへ変換しない。

選択肢は各版の掲載中商品の主要成分から、`ingredientSelection()` でまとまりを作って五十音順に表示する。女性168・男性86項目。男女版のDBを共通化したり、選択できる成分を解説の掲載数で制限したりしない。CSVの主要成分は全成分表示ではないため、未登録の配合成分まで検索できるとは限らない。

## 選択欄のまとまり

「この仲間のどれかを含む商品を使いたい」という指定にする。化学物質・原料規格・濃度・効果が同一という意味ではない。

コエンザイムQ10は「こえんざいむ」の読みで並べる。旧設定のユビキノン・ユビデカレノンはコエンザイムQ10へ移行し、元の成分名でも解説を検索できる。解説の `#coenzyme-q10` は維持する。

v0.9.27で「50の恵 養潤液」「養潤クリーム」の主要成分にユビキノンを補完した。メーカー公式で配合を確認できる既存商品だが、登録漏れにより女性版の成分指定から対象にできていなかった。選択欄の項目数や登録件数を、市場での配合製品数とみなさない。[照合記録](../catalog/q10-ingredient-audit.md)に同一JANと出典を記録する。

### 原料規格の番号と注釈（v0.9.26）

「アロエエキス(2)」は[厚生労働省の原料名リスト](https://www.mhlw.go.jp/web/t_doc?dataId=00tc5776&dataType=1&pageNo=1)に成分コード520095として掲載され、[メーカーの成分表示](https://onlineshop.finetoday.com/products/uno-54)にも使われる名称。(2)は脚注・配合濃度ではなく、原料規格の区分。[PMDA掲載の規格](https://www.pmda.go.jp/files/000240227.pdf)では、アロエの葉の液汁からアロインを除去して得た粉末を、水・エタノール・PG・BGなどで抽出または溶解した原料と定義されている。「油溶性甘草エキス(2)」も[原料供給元の医薬部外品名称](https://www.cosfa.co.jp/business/cosmetics/products/amakusa/)で確認した。

これら2項目は選択欄と解説見出しだけを簡略化し、メーカー表示・旧設定・旧解説URLは保持する。括弧を一括削除する処理は使わない。POE(26)グリセリンの数字や、トリ（カプリル酸／カプリン酸）グリセリルの括弧も保持する。

男女の主要成分・有効成分欄を点検し、雪肌精 ホワイト クリーム ウォッシュ（JAN 4971710262131）で説明文の混入1件を訂正した。[公式ページ](https://sekkisei.jp/site/blue/g/gMTNC/)の全成分は「酸化チタン」で終わり、その後のハトムギ発酵エキスに関する別行の説明が同じ成分としてつながっていた。価格・使用量・採点は据え置き。`catalog-csv.js` は注釈記号や説明文を含む成分欄を読み込み時に拒否し、正式な番号・構造名の括弧を受理する。

Na・Kなどの文字を一括削除する処理は使わない。構造と用途を確認した表示名を、選択用の対応表に明示する。酸とその塩は、処方のpHに応じた酸塩基平衡に関わるが、同じ表示濃度や同じ効能を保証しない。対イオンや中和度によって溶解性・泡立ち・製品のpHが変わるため、解説に違いを残す。酸・共役塩・pHの関係は[原料メーカーの緩衝系資料](https://www.jungbunzlauer.com/wp-content/uploads/2025/06/JBL_FL_Jungbunzlauer_ingredients_as_buffering_agents_2022-070.pdf)を参照。

ミリスチン酸の遊離酸はクリームの質感調整等にも、塩は石けんとして洗浄にも使われる。ここでは広い成分指定としてまとめ、製品の用途は元のCSVで判定する。ミリスチン酸イソプロピルのようなエステル、脂肪酸鎖の異なるココイル／ラウロイル、PCA亜鉛のように金属イオン側の用途があるものへ機械的に広げない。粉体の含水量・結晶性・粒径による違いも同義語扱いにはせず、解説に補足する。

必須・優先の10点加点・任意品目を候補に入れる判定は、すべて同じ選択名に分類されるかで照合する。過去に保存した「ヒアルロン酸Na」なども、読み込み時に「ヒアルロン酸」へ移行する。元の成分名を変換したり、部分文字列一致で関連のない成分を拾ったりしない。

## 分けて扱うもの

メーカー表示、化学的な同義語、使ってみたい成分の分類は別管理。ヒアルロン酸の種類やセラミドの種類は選択欄でまとめるが、原料名・性質の違いは解説とメーカー情報に残す。

レチノールと酢酸レチノール、グリセリンとジグリセリン、セリンとメチルセリン、保湿のアミノ酸とアミノ酸系洗浄成分、カモミラETとカミツレエキス、ユーカリエキスとユーカリ葉油は別の選択項目にする。ライスパワーNo.11・11+・6・7-Aも薬用での用途が異なるため別項目。

肌悩み点・7/3/1倍の重複処理・手間点・成分種類数の加点・探索アルゴリズムは変更していない。成分指定があるときは、その仲間のいずれかを含む商品が対象になるため、以前より候補が広がる場合がある。成分種類数の採点は従来どおり元の主要成分文字列を用いる。

## 解説の編集・生成

- 編集元：`data/ingredient-dictionary.mjs` は成分名ごとの主な用途・短い説明・種類の補足を管理。`data/ingredient-guide.mjs` は研究の対象・限界・一次資料の記録として利用する。
- 出力：`dist/ingredients.html`（JavaScriptなしでも読める本文）と `dist/ingredient-guide-index.js`（アプリのリンク用）。`npm run guide:build` で生成。
- `npm run guide:check` とテストで、男女両DBのすべての選択名から実在する解説IDへ到達できること、解説IDの重複がないこと、生成物の一致を確認。今後成分を追加したときも未掲載を検出する。
- 解説は204項目。肌悩み・役割別の大見出しを廃止し、成分名の読みの五十音順に並べる。目次は「あ行・か行…」。各見出しに「主な用途」と短い説明を載せ、種類・メーカー表示例と研究・出典は開いて読めるようにする。
- メーカー表示の例と、配合製品の公式URLも各項目に掲載。元の48項目のアンカーと、統合前の成分名から作られた見出しIDを互換用に残す。
- 検索は別表記・全角半角・ひらがな／カタカナに対応。役割別の選択欄は置かない。検索で本文を隠していても、目次やハッシュ移動では検索を解除する。

## 論文の扱い

確認日は編集元の `checkedOn`。各カードに原著のPubMedリンク・PMID、確認できたDOI、試験の種類・条件と限界を記録する。メーカーの用途・原料資料を臨床試験として表示しない。論文番号を確認できない研究紹介には番号を作らず、メーカーの公開資料へリンクする。

既存5項目の参考論文に、レチノール（PMID 17515510）、トラネキサム酸（27135282）、アスコルビン酸（12823436）、グリセリン／ワセリン配合クリーム（31532576）を追加。細胞・動物・ヒトでの試験、対照群の有無、使用部位・濃度・期間を区別する。内服・注射の研究を外用化粧品へ当てはめない。

価格・JAN・メーカー成分表示の照合ルールは従来の各カタログの記録を優先し、この解説に記載した原料情報から商品DBの値を作らない。
