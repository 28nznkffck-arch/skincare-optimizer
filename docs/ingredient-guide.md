# 成分の表記・解説の管理

更新日：2026-11-26 ／ v0.9.35

## 表示と元データ

`catalog/`・`catalog-men/` の「配合成分」には、全563品の全成分表示を省略せず表示順に保存する。選択肢や解説の有無は登録条件に使わない。原文・出典URL・出典種別・確認日もCSVと `ingredient-sources.json` に保持する。[全成分登録記録](ingredient-coverage-audit.md)を参照。価格・使用量・肌悩み点の元データは変更していない。

商品カードは `keyIngredients` のメーカー記録をそのまま表示する。商品表示を、選択欄のまとまりや正規化名で書き換えない。

`dist/ingredient-options.js` では、同義語の確認用 `canonicalIngredient()` と、選択用の分類 `ingredientSelection()` を分ける。同義語の確認では全角英数・括弧・スラッシュをNFKCで統一し、根拠のある別名を対応表でまとめる。カタカナの長音は一律にハイフンへ変換しない。

選択肢は各版の掲載中商品の配合成分から、`ingredientSelections()` で複合原料の構成も認識し、五十音順に表示する。女性1010・男性421項目。解説の掲載数で登録・選択を制限しない。成分索引1102項目のうち、従来の一次資料付き205項目は既存の根拠を保持し、新しい名前は配合表示の出典と「用途の確認中」を表示する。`npm run ingredients:check` は選択用の辞書を使わず原本記録の全項目・順序・原文・出典・確認日と照合する。新しいJANや公式URL変更時も原本を確認する。

## 選択表示名の読みやすさと追加名寄せ（v0.9.34）

## ビタミンA表示名と重複候補の追加整理（v0.9.32）

「使ってみたい成分」の「ビタミンA」を**「レチノール(ビタミンA)」**に改名。「ビタミンA」「レチノール」「酢酸レチノール」「パルミチン酸レチノール」「ビタミンA油」は同じ選択カテゴリを参照する。成分原文や成分別の効能を同一視せず、旧「ビタミンA」カテゴリのURLアンカーと保存値は引き継ぐ。

**グリチルリチン酸ジカリウム**は「2K」「二カリウム」の既存同義語に加え、メラノCC 1品の配合成分原文にある「グリチルリチリン酸ジカリウム」を1文字違いの表記として名寄せした。原文自体は修正しない。正式な原料名は[厚生労働省の医薬部外品添加物リスト](https://www.mhlw.go.jp/web/t_doc?dataId=00tc7231&dataType=1&pageNo=1)で確認。「グリチルリチン酸アンモニウム」「グリチルレチン酸ステアリル」は別成分として残す。

**その他の同義語・表記整理（21組）**：Naとナトリウム、PEG-60とPEG60、水添ヒマシ油、カルボキシメチルセルロースNa、ピロ亜硫酸Na、メタリン酸Na、ポリアクリル酸Na、ミリストイルメチルタウリンNa、セテアレス-25、パルミチン酸エチルヘキシル、オクチルドデカノール、ライスパワーNo.6の登録商標表記、サクランの®表記、HCl／HCIや枝／技などの誤記と思われる形もメーカー原文を残して名寄せした。

**選択用の同系統グループ（15組）**：オリーブ油、ローズマリー油、アスナロ・ツバキ由来エキス、加水分解コンキオリン、コレステロール、フィトステロール、ラウロイルアスパラギン酸Na、サクシノグリカン、メチルセリン、ソルビタン脂肪酸モノエステル3種、ポリグリセリン、PEG水添ヒマシ油。加えて「アロエエキス-2」を既存のアロエエキスへ統合。液状原料・植物部位・脂肪酸構造・PEG鎖長が異なる場合は選択上のみのグループで、化学的な同義語と混同しない。グリセリンとジグリセリン、ローズマリー油とローズマリーエキスは別の項目。

## アーティチョーク・ビタミン類・複合原料（v0.9.31）

**アーティチョーク**：「アーティチョークエキス」と「アーチチョーク葉エキス」を同じ選択名にする。原料メーカー[一丸ファルコス](https://www.ichimaru.co.jp/dev/cosmetics/261)の化粧品表示／医薬部外品表示名の対応を参照。メーカーの表示名と配合成分の原文は書き換えない。

**ビタミン類**：「ビタミンA」へレチノール・酢酸レチノール・パルミチン酸レチノール・ビタミンA油、「ビタミンB6」へピリドキシンHCl・塩酸ピリドキシン等、「ビタミンC」へアスコルビン酸硫酸2Naやリン酸L-アスコルビルマグネシウム、括弧の説明が付いたアスコルビン酸類、「ビタミンE」へ天然ビタミンE・トコフェリルグルコシドも含める。これは**使ってみたい成分の分類**であり、同一の化合物・有効成分・配合率・効果を示さない。レチノールのシワ改善の根拠はビタミンA油やレチノールエステルへ外挿しない。塩酸ピリドキシンとビタミンB6の対応は[厚生労働省の医薬部外品原料規格](https://www.mhlw.go.jp/content/000839905.pdf)を参照。

## 解説の編集・生成

- 編集元：`data/ingredient-dictionary.mjs` は成分名ごとの主な用途・短い説明・種類の補足を管理。`data/ingredient-guide.mjs` は研究の対象・限界・一次資料の記録として利用する。
- 出力：`dist/ingredients.html`（JavaScriptなしでも読める本文）と `dist/ingredient-guide-index.js`（アプリのリンク用）。`npm run guide:build` で生成。
- `npm run guide:check` とテストで、男女両DBのすべての選択名から実在する解説IDへ到達できること、解説IDの重複がないこと、生成物の一致を確認。今後成分を追加したときも未掲載を検出する。
- 解説の既存205項目を含めて現在1234項目。肌悩み・役割別の大見出しを廃止し、成分名の読みの五十音順に並べる。目次は「あ行・か行…」。各見出しに「主な用途」と短い説明を載せ、種類・メーカー表示例と研究・出典は開いて読めるようにする。
- メーカー表示の例と、配合製品の公式URLも各項目に掲載。元の48項目のアンカーと、統合前の成分名から作られた見出しIDを互換用に残す。
- 検索は別表記・全角半角・ひらがな／カタカナに対応。役割別の選択欄は置かない。検索で本文を隠していても、目次やハッシュ移動では検索を解除する。
