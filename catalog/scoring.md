# 肌悩み別の採点基準

[点数表](scores.csv)は1 JANにつき1行。肌悩み別の点数と、その点を付けた理由を「採点メモ」に記録する。商品の成分、製品ごとの出典、確認日は[商品マスター](products.csv)の同じJANを参照する。2026-11-14に現行120商品の17項目を再採点し、2026-11-15に「肌の明るさ」を追加した。

| 点数 | 採点の目安 |
| --- | --- |
| 3 | 肌悩みに直接対応する主作用。薬用効能は、該当する有効成分の配合と製品の適用範囲を確認する。乾燥や洗浄の悩みでは、処方の働きと使い方を確認する |
| 2 | 製品で確認できる副次的な作用、洗い流す薬用製品の副次用途、または試験で確認された乾燥小じわへの保湿効果など、範囲が限られる作用 |
| 1 | 肌悩みへの補助。成分単体のヒト外用試験を登録製品に当てはめる場合は、分かっている濃度や用途を考慮し、製品としての根拠がなければ最大1点 |
| 0 | 採点済み。確認した資料で加点できる根拠が見つからなかった |
| 空欄 | 未採点 |

複数の理由が同じ悩みに当てはまる場合は、最も根拠のある点を採る。同じ作用を成分数分だけ足し上げることはしない。点数は推薦での適合度を比較するための重みで、効果の大きさを測った値ではない。

## 作用の確認

| 肌悩み | 判定する内容 |
| --- | --- |
| シミ・そばかす | カモミラET、アスコルビン酸、L-アスコルビン酸2-グルコシド、トラネキサム酸、ナイアシンアミドのうち、その製品でメラニン生成抑制による予防に対応するものを評価。既存のシミ・そばかすを消す効能としては扱わない |
| シワ・小ジワ | 薬用シワ改善に用いるナイアシンアミドは両方を評価。保湿で乾燥小じわを目立ちにくくする効能評価試験が確認できた商品には小ジワだけに付与する |
| 肌荒れ・ニキビ | アラントイン、グリチルリチン酸ジカリウム、グリチルレチン酸ステアリル、ガンマ-アミノ-ベータ-ヒドロキシ酪酸は、肌荒れ予防の有効成分として確認した製品を評価。ニキビはイソプロピルメチルフェノールなどを含む薬用処方で予防の適用が確認できる場合、または洗浄による予防が確認できる場合に評価する |
| 毛穴・黒ずみ／角栓 | 角栓、余分な皮脂、毛穴の汚れの洗浄や、保湿による毛穴の見え方への作用を確認。毛穴のメイク汚れの洗浄と、黒ずみ・角栓を洗い落とす作用は区別する |
| ベタつき・テカリ | 過剰な皮脂を洗い流す処方や、その製品で確認できるベタつき抑制を評価。ベタつかない使用感だけでは加点しない |
| くすみ・乾燥・ハリ不足 | 乾燥ぐすみへの保湿や、古い角質などによるくすみの洗浄を評価。保湿成分による角層のうるおい、うるおいや塗膜によるハリ感を、各項目で扱う |
| 肌の明るさ（明るくしたい） | 保湿成分や洗浄処方の働きから、顔全体を明るい印象に整えるケアを評価。例えば保湿で乾燥ぐすみをケアする作用や、古い角質・皮脂汚れによるくすみを洗い落とす作用を対象とする。点数は共通基準を使い、主作用・副次的な作用・間接的な補助のどれに当たるかで決める。地肌の色は評価せず、「シミ・そばかす」の予防効能だけでは加点しない |
| 色ムラ・赤み | 外用研究の評価対象と合う場合に補助点。色ムラは色素性、赤みは研究で対象になった光老化肌の赤みムラの範囲。肌荒れ予防の成分が入っていることだけで赤みには加点しない |
| 目元の乾燥・クマ | 目元用として確認した保湿処方は目元の乾燥で評価。クマの見え方に直接対応する根拠が見つかった商品は現行登録品にないため、全品0点 |

薬用製品では、有効成分の表示と承認された効能の範囲を突き合わせる。化粧品でも、実際に配合された保湿成分・洗浄成分や処方の働きから評価できる。メーカーの用途説明は、成分の役割、使い方、効能評価の有無を確認する資料として使う。

## 採点に用いた成分研究

1. [Bissettほか、ナイアシンアミド外用試験](https://pubmed.ncbi.nlm.nih.gov/18492135/) ／ [掲載誌の抄録](https://doi.org/10.1111/j.1467-2494.2004.00228.x)。ナイアシンアミド5%配合の保湿剤と基剤を比較した12週間の試験。光老化した肌の赤みムラ、色素斑、シワ・小ジワを評価。対象と処方が限定されるため、登録品では該当する肌悩みの補助点としてのみ使う。
2. [Hakozakiほか、ナイアシンアミドと色素沈着](https://pubmed.ncbi.nlm.nih.gov/12100180/)。ナイアシンアミドを外用し、顔の色素沈着への作用を調べた試験。色素によるムラやシミへの補助点に用いる。そばかすの予防点は上表の製品ごとの効能に基づく。

## 配合量の情報公開

メーカーが対象の処方について公開した成分名・配合量の数値・単位・出典URLが揃ったら、商品マスターの「配合濃度（JSON）」に登録する。原料混合物の量や成分表の掲載順から個別成分の配合量を推測しない。配合量の数値が未確認の場合は空欄にする。肌悩み別点数とは別に、出典付きの配合量がある商品の割合に応じて、組み合わせに最大1.05点を加える。2026-11-14の登録品では数値を確認できたものはなかった。
