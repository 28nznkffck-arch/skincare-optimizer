# 肌悩み別の採点基準

[点数表](scores.csv)は1 JANにつき1行。肌悩み別の点数と、その点を付けた理由を「採点メモ」に記録する。商品の成分、製品ごとの出典、確認日は[商品マスター](products.csv)の同じJANを参照する。2026-11-14に現行120商品の17項目を再採点し、2026-11-15に「肌の明るさ」を追加した。

| 点数 | 採点の目安 |
| --- | --- |
| 3 | 肌悩みに直接対応する主作用。薬用効能は、該当する有効成分の配合と製品の適用範囲を確認する。乾燥や洗浄の悩みでは、処方の働きと使い方を確認する |
| 2 | 製品で確認できる副次的な作用、洗い流す薬用製品の副次用途、または試験で確認された乾燥小じわへの保湿効果など、範囲が限られる作用 |
| 1 | 肌悩みへの補助。成分単体のヒト外用試験を登録製品に当てはめる場合は、分かっている濃度や用途を考慮し、製品としての根拠がなければ最大1点 |
| 0 | 採点済み。確認した資料で加点できる根拠が見つからなかった |
| 空欄 | 未採点 |

複数の理由が同じ悩みに当てはまる場合は、最も根拠のある点を採る。同じ作用を成分数分だけ足し上げることはしない。点数は推薦での適合度を比較するための重みで、効果の大きさを測った値ではない。

## 作用の確認

| 肌悩み | 判定する内容 |
| --- | --- |
| シミ・そばかす | 新しくできるのを防ぐ作用と、すでにある色素斑を薄くする作用を評価。前者は製品の薬用効能と有効成分を照合する。後者は、対応する種類の色素斑に製品または成分を外用したヒト試験を参照する。採点メモには予防と既存の色素斑への作用を記録し、点数欄には高い方を採用する |
| シワ・小ジワ | 薬用シワ改善に用いるナイアシンアミドは両方を評価。保湿で乾燥小じわを目立ちにくくする効能評価試験が確認できた商品には小ジワだけに付与する |
| 肌荒れ・ニキビ | アラントイン、グリチルリチン酸ジカリウム、グリチルレチン酸ステアリル、ガンマ-アミノ-ベータ-ヒドロキシ酪酸は、肌荒れ予防の有効成分として確認した製品を評価。ニキビはイソプロピルメチルフェノールなどを含む薬用処方で予防の適用が確認できる場合、または洗浄による予防が確認できる場合に評価する |
| 毛穴・黒ずみ／角栓 | 角栓、余分な皮脂、毛穴の汚れの洗浄や、保湿による毛穴の見え方への作用を確認。毛穴のメイク汚れの洗浄と、黒ずみ・角栓を洗い落とす作用は区別する |
| ベタつき・テカリ | 過剰な皮脂を洗い流す処方や、その製品で確認できるベタつき抑制を評価。ベタつかない使用感だけでは加点しない |
| くすみ・乾燥・ハリ不足 | 乾燥ぐすみへの保湿や、古い角質などによるくすみの洗浄を評価。保湿成分による角層のうるおい、うるおいや塗膜によるハリ感を、各項目で扱う |
| 肌の明るさ（明るくしたい） | シミのない部分も含む素肌全体の色調を明るくする作用と、紫外線による色素沈着で肌が濃くなるのを防ぐ作用を評価する。ヒト外用試験の対象部位・使い方を照合し、改善と予防の両方に根拠がある場合は高い方を採用する。乾燥ぐすみの保湿や古い角質・皮脂汚れの洗浄は「くすみ」で扱う |
| 色ムラ・赤み | 外用研究の評価対象と合う場合に補助点。色ムラは色素性、赤みは研究で対象になった光老化肌の赤みムラの範囲。肌荒れ予防の成分が入っていることだけで赤みには加点しない |
| 目元の乾燥・クマ | 目元用として確認した保湿処方は目元の乾燥で評価。クマの見え方に直接対応する根拠が見つかった商品は現行登録品にないため、全品0点 |

薬用製品では、有効成分の表示と承認された効能の範囲を突き合わせる。化粧品でも、実際に配合された保湿成分・洗浄成分や処方の働きから評価できる。メーカーの用途説明は、成分の役割、使い方、効能評価の有無を確認する資料として使う。

薬用美白の表示にある「シミ・そばかすを防ぐ」は予防の効能として採点する。既存の色素斑は、日光性色素斑、肝斑、そばかすなど、試験が対象にした範囲で評価する。配合されている成分の種類、濃度、剤型、塗布部位を確認し、成分研究からの補助点は共通基準どおり最大1点。シミを薄くする研究をそばかすにも当てはめたり、異なるビタミンC誘導体で点数を引き継いだりしない。 [厚生労働省「化粧品・医薬部外品の効能・効果の範囲」](https://www.mhlw.go.jp/file/06-Seisakujouhou-11120000-Iyakushokuhinkyoku/0000179263.pdf)

## 照合した成分研究

1. [Bissettほか、ナイアシンアミド外用試験](https://pubmed.ncbi.nlm.nih.gov/18492135/) ／ [掲載誌の抄録](https://doi.org/10.1111/j.1467-2494.2004.00228.x)。ナイアシンアミド5%配合の保湿剤と基剤を比較した12週間の試験。光老化した肌の赤みムラ、色素斑、シワ・小ジワを評価。対象と処方が限定されるため、登録品では該当する肌悩みの補助点としてのみ使う。
2. [Hakozakiほか、ナイアシンアミドと色素沈着](https://pubmed.ncbi.nlm.nih.gov/12100180/)。5%配合の保湿剤で顔の色素斑、日焼けした顔に使う2%配合の日焼け止め処方で顔の明度への作用を評価した。素肌の明るさは日焼けした肌の研究を参照し、全顔用の配合確認品に補助点を付ける。登録品の濃度と処方の同等性は未確認。
3. [Bissettほか、N-アセチルグルコサミンの外用試験](https://pubmed.ncbi.nlm.nih.gov/17348991/)。2%配合で8週間の基剤対照試験を行い、顔の色素沈着が目立ちにくくなった。アセチルグルコサミン（酢酸キトサミン）を含む、顔に塗ったまま使う製品のシミへの補助点に用いる。
4. [Espinal-Perezほか、アスコルビン酸5%と肝斑](https://pubmed.ncbi.nlm.nih.gov/15304189/)／[Khemisほか、アスコルビン酸10%・フィチン酸2%と日光性色素斑](https://pubmed.ncbi.nlm.nih.gov/22151934/)。前者は16人の半顔試験で、アスコルビン酸側でも改善を報告した。比較相手はハイドロキノンで基剤対照はなく、両側で日焼け止めを併用した。後者は基剤対照で既存の斑の色が薄くなった配合例。登録アスコルビン酸美容液が試験と同じ濃度・処方かは未確認のため、シミへの補助点とする。
5. [アスコルビン酸2-グルコシド・アルギニン複合体の試験](https://pubmed.ncbi.nlm.nih.gov/39769217/)／[リン酸アスコルビルナトリウムの試験](https://pubmed.ncbi.nlm.nih.gov/30778667/)。それぞれ複合体28%、リン酸アスコルビルナトリウム6%の試験処方で、既存の日光性色素斑とその周囲の肌の明度に変化が出た。登録品にあるL-アスコルビン酸2-グルコシドには[紫外線による色素沈着の抑制試験](https://www.jstage.jst.go.jp/article/nishinihonhifu/58/3/58_3_439/_article/-char/ja/)がある。登録品では公式で確認したシミ・そばかすの予防に加え、肌全体の色調が濃くなることへの予防を補助点とする。
6. [水溶性プラセンタ配合品の使用試験](https://www.shinryo-to-shinyaku.com/db/pdf/sin_0056_03_0211.pdf)。21人、4週間の半顔試験で、使用側は不使用側より測定した明度と「隠れジミ」の指標が改善した。プラセンタだけを除いた処方との比較や、目で見える既存の色素斑が薄くなったかの評価は確認できなかった。薬用美白の効能を確認できる製品は予防を評価し、既存のシミ・そばかすの点数は別の根拠を確認して決める。

7. [de Dormaelほか、アスコルビン酸と紫外線による色素沈着](https://pubmed.ncbi.nlm.nih.gov/30881584/)。紫外線照射時の色素沈着を抑えた複数のヒト外用試験の解析。アスコルビン酸を配合した登録品では、濃度や試験処方との同等性が未確認のため予防の補助点とする。
8. [小林ほか、カミツレエキスの紫外線色素沈着抑制試験](https://doi.org/10.11340/skinresearch1959.41.475)／[花王のカモミラETの説明](https://www.kao.com/jp/skincare/surface/research-01/)。カミツレ抽出物0.5%配合のクリームを前腕に使用し、紫外線照射後の色素沈着の抑制を評価。カモミラETを配合した登録品では、濃度や試験処方との同等性が未確認のため予防の補助点とする。

## 配合量の情報公開

メーカーが対象の処方について公開した成分名・配合量の数値・単位・出典URLが揃ったら、商品マスターの「配合濃度（JSON）」に登録する。原料混合物の量や成分表の掲載順から個別成分の配合量を推測しない。配合量の数値が未確認の場合は空欄にする。肌悩み別点数とは別に、出典付きの配合量がある商品の割合に応じて、組み合わせに最大1.05点を加える。2026-11-14の登録品では数値を確認できたものはなかった。
