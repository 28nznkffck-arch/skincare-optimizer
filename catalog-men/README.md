# 男性向け商品DB（独立管理）

このディレクトリは `/men/` 専用です。女性版の `catalog/` とは商品マスター、価格、採点を共有しません。最適化エンジンとCSVスキーマは共通です。

- `products.csv`: JAN、製品区分、製品・成分の出典、仮使用回数
- `prices.csv`: JANと一致するマツキヨココカラオンラインの税込通常価格、確認日
- `scores.csv`: 肌悩みごとの暫定評価。0は未配合の意味ではありません
- `metadata.json`: 公開時の案内

2026-11-21時点の**初期9品**のみ。全商品を網羅した状態ではありません。洗顔4、保湿3、化粧水2。メイク落とし・美容液・目元ケアは未登録です。日焼け止め・数量限定品は対象外です。

**注意:** 使い切り期間が確認できていないため、1本の使用回数は仮値（洗顔60回、それ以外120回）です。実際の月額費用とは異なり得ます。スコアもメーカーが保証する効果量ではありません。医薬部外品のみ確認できた有効成分を記録し、化粧品の保湿成分は有効成分に読み替えません。

登録手順とスキーマは `../README.md` を参照。検証は `npm test`。
