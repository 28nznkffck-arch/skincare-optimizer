# 男性向けスキンケア商品DB（/men/専用）

女性版の `catalog/` とは、`products.csv`・`prices.csv`・`scores.csv` を完全に分離。アプリの選定エンジンとCSVスキーマは共通です。

**2026-11-22現在：36品**（メンズビオレ14品、ニベアメン11品、OXY3品、uno4品、ギャツビー4品）。

品目：洗顔20品、メイク落とし1品、化粧水8品、保湿7品。美容液・目元ケアは未登録。日焼け止めや数量限定品は対象外。

価格はJAN一致のドラッグストア通販税込通常価格をマツキヨ→ツルハ→ウエルシアの順で確認し、追加11品はマツキヨ8品、ツルハ3品。初期花王製品の確認先は [花王登録監査](kao-registration-audit-2026-11-21.md)、今回追加した3ブランドの確認先は [追加監査](additional-brands-audit-2026-11-22.md) に記録。

- メンズビオレONE クレンジングジェル洗顔料はBB・UVなどを落とす洗顔料なので、「メイク落とし」枠でW洗顔不要としています。耐水性メイク全般を落とせると保証するものではありません。
- ニベアメン アクティブエイジ ワンステップケアは洗顔にも乳液にも使えますが、共通エンジンでは1品を2枠で同時に利用できないため、現状は洗顔枠のみで登録しています。
- ミクロスクラブ洗顔のみメーカー平均1g/回から使用回数を試算。他の35品の使用回数と選定スコアは暫定値であり、効果や費用を保証しません。
- 医薬部外品の有効成分と化粧品の一般配合成分を区別して登録しています。

検証コマンド：`npm run catalog:check` / `npm test`。女性版の既存データと保存設定には影響しません。
